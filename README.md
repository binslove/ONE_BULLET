# ONE BULLET — 단 한 발

한 발의 궤적을 설계하고, 되찾고, 이어가는 2D 탑다운 리코셰 슈팅 액션.

**실행**: `index.html` 을 브라우저로 열면 됩니다. (빌드 · 설치 · 서버 불필요)

## 조작

| 입력 | 기능 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 | 발사 (장전 상태에서만) |
| Space | 대시 (무적 · 회피) |
| E | 퍼펙트 캐치 / 탄환 회수 |
| ESC | 설정 (화면 흔들림 · 음량 · 조준 보조선) |

## 핵심 규칙

플레이어가 가진 총알은 한 발뿐이다. 발사한 탄환을 회수하기 전에는 다시 공격할 수 없다.

```
LOADED ──발사──→ FLIGHT ──도탄 4회/비행 2.8초──→ RETURNING ──퍼펙트 캐치──→ LOADED (CHAIN +1)
                    │                                │
                 적 명중                          회피·빗나감
                    ↓                                ↓
                 DROPPED ←──────────────────────── DROPPED ──접근 회수──→ LOADED (CHAIN 0)
```

지형에 박히거나 구역을 벗어난 탄환은 **원래 자리 근처의 접근 가능한 지점**으로 복구된다.

## ONE CHAIN

| 단계 | 조건 | 효과 | 사운드 |
|---|---|---|---|
| 0 | 바닥에서 회수 | 기본 | 건조한 발사음 |
| 1 | 퍼펙트 캐치 1회 | 피해 ×1.25 | 금색 잔상 강화 |
| 2 | 연속 2회 | 탄환 속도 +10% | 저음 리듬 레이어 |
| 3 | 연속 3회 | 적 1기 관통 | 아르페지오로 음악 완성 |

캐치 후 1초 안에 재발사하지 않으면 체인은 소멸한다. 바닥 회수 · 귀환 탄환 피격 시 즉시 0.

## 구성

| 파일 | 내용 |
|---|---|
| `src/util.js` | 벡터 · 광선/선분 교차 · 반사 · 폴리곤 충돌 · 드로잉 |
| `src/audio.js` | WebAudio 절차적 사운드, 체인 연동 3단계 배경음 레이어 |
| `src/levels.js` | 5개 구역 데이터 (지형 · 적 · 기믹 배치) |
| `src/game.js` | 상태 기계 · 탄환 물리 · 적/보스 AI · SHOTPRINT · HUD |

**구역**: 회수 → 반사 → 방패 → 탈취 → 보스(실험체 ZERO). 각 구역은 새 요소를 하나만 추가한다.

**적 4종** 추격병 · 사수 · 방패병 · 수집병
**전투 오브젝트 4종** 일반 벽 · 회전 반사판 · 균열 벽 · 충전 장치
**환경 기믹 4종** 폭발 드럼 · 압력 가시판 · 레이저 셔터 · 회전 스위치
**탄환 강화 2종** 전기(최대 2대상 전이) · 폭발(첫 명중 범위 피해)

## SHOTPRINT

발사 · 도탄 · 명중 · 캐치 지점을 기록해, 구역 클리어 시 배경을 어둡게 전환하고 전체 탄도를 3초 동안 금색 선으로 재생한다. 최종 보스의 SHOTPRINT 는 결과 화면의 대표 이미지로 쓰인다.
